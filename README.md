# Be Conscious 🥗
> **Know what you eat. Choose what matters.**

Be Conscious is a modern, responsive, user-friendly food awareness web application designed to help consumers decode what is really inside their packaged foods. Scan barcodes to uncover calories, nutritional values, ingredients, allergens, and food processing degree (NOVA classification) without confusing marketing slogans.

---

## ✨ Features

- **Food Scanner & Decoder**: Interactive simulated scanner viewfinder with target brackets and manual barcode entry.
- **Deep Nutritional Analysis**:
  - Interactive Macronutrient Donut Chart (Carbs, Fats, Protein, Fiber per 100g) powered by Recharts.
  - NOVA Ultra-Processed Index Classification (Groups 1–4).
  - Chemical additives and E-numbers detection.
  - Allergen alerts and sensitivity warnings.
- **Explore Conscious Catalog**: Filterable catalog by categories (Snacks, Dairy, Beverages, Cereals) and NOVA processing degrees.
- **My Scan History**: Local storage-persisted log of decoded items and saved favorites.
- **About & Methodology**: Explanations of NOVA classification, nutritional calculations, and food transparency philosophy.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```
Visit `http://localhost:3000/` in your browser.

### 3. Build for Production
```bash
npm run build
```
